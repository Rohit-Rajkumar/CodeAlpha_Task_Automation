# CodeAlpha Task Automation

## Description
A Python automation script that extracts email addresses from a text file using regular expressions and saves them to an output file.

## Features
- Extracts valid email addresses
- Uses Regular Expressions (Regex)
- Saves results to a text file
- Simple and beginner-friendly

## Technologies Used
- Python 3
- re (Regular Expressions)
